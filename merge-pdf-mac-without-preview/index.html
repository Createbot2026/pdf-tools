Merge PDFs on a Mac

On a Mac you can merge in Preview by dragging page thumbnails between documents, but it is fiddly with many files. This tool merges any number of PDFs in one go, locally in Safari, Chrome or Firefox.

Drop files here or

    🔒 Runs entirely in your browser. Files are never uploaded.

    How to do it

    1. Choose your PDFs here (Cmd-click to select several).
    2. Order with ↑ and press Merge.
    3. Or in Preview: open the first PDF, show thumbnails (View → Thumbnails), drag other PDFs into the sidebar, then File → Export as PDF.

    Tips and limits

    • Preview edits the original file in place: duplicate it first.

    Frequently asked questions

    Which is better, Preview or this tool?

    Preview is fine for two files. For many files or exact ordering, this tool is quicker.

    Is my file uploaded anywhere?

    No. The tool runs in your browser with JavaScript. The PDF is read from your device, processed in memory and saved back to your device. You can switch off Wi-Fi after the page loads and it still works.
