Add page numbers to a PDF

Bundles, dissertations and evidence packs are easier to navigate with page numbers. Add them locally without Acrobat.

Drop a file here or

    🔒 Runs entirely in your browser. Files are never uploaded.

    How to do it

    1. Choose the PDF.
    2. Pick start number, format (1 / 10 or Page 1) and position.
    3. Press Add page numbers.
    4. Download and check the first and last pages.

    Tips and limits

    • Bottom centre is the usual choice for formal bundles.
    • If pages already have numbers in the margin, pick a different corner.
    • Numbering does not change page order.

    Frequently asked questions

    Can I skip the cover page?

    Add numbers starting at 1 on page 2 by extracting page 1 first, numbering the rest, then merging the cover back — or start at 0 and trim. A dedicated “skip first” control is on the roadmap.

    Is my file uploaded anywhere?

    No. The tool runs in your browser with JavaScript. The PDF is read from your device, processed in memory and saved back to your device. You can switch off Wi-Fi after the page loads and it still works.
