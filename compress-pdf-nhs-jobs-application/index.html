Compress a PDF for an NHS Jobs application

NHS application systems let you attach supporting documents such as certificates, registration evidence and sometimes a CV. Upload limits apply per file and the forms time out if you take too long, so get your PDFs sized before you start.

Drop a file here or

    🔒 Runs entirely in your browser. Files are never uploaded.

    How to do it

    1. Gather certificates (NMC/HCPC registration, DBS, qualifications) as PDFs.
    2. Merge related certificates into one file if the form only allows a few attachments.
    3. Compress here with the 2MB default, or set the limit shown on the form.
    4. Upload the compressed copies.

    Tips and limits

    • The supporting statement usually goes into a text box, not a PDF, so check what is actually requested.
    • Name files clearly, e.g. "Surname-NMC-registration.pdf".
    • Certificates scanned in colour compress much smaller in greyscale.

    Frequently asked questions

    What file size does NHS Jobs accept?

    Limits vary between systems and change over time. Use the figure shown on the upload screen as your target.

    Is my file uploaded anywhere?

    No. The tool runs in your browser with JavaScript. The PDF is read from your device, processed in memory and saved back to your device. You can switch off Wi-Fi after the page loads and it still works.
