Compress PDFs for a UK visa application

UK visa applications ask for sensitive evidence: passports, bank statements, payslips, tenancy agreements. Online upload services set per-file size limits and some reject files that are too large. Because these are your most sensitive documents, compressing them locally rather than on a random upload site is the safer choice.

    How to do it

    1. Scan or save each document as a PDF (one document per file usually works best).
    2. Choose a file here; the default target is 2MB. Check the current limit shown on your upload page and change the target if needed.
    3. Press Compress and download.
    4. Open the result and confirm figures on bank statements are still readable.

    Tips and limits

    • Caseworkers need to read amounts and dates: zoom to 100% and check before you upload.
    • Combine several months of statements with the merge tool, then compress once.
    • Keep originals; you may be asked for them later.
    • Never upload passports or statements to tools that store files on a server if you can avoid it.

    Frequently asked questions

    What is the UK visa document size limit?

    It depends on the service you are directed to and can change, so always check the limit stated on your upload page. Set that number (in KB) as the target here.

    Is it safe to compress my passport scan here?

    The file is processed only in your browser and is not uploaded, stored or seen by anyone.

    Is my file uploaded anywhere?

    No. The tool runs in your browser with JavaScript. The PDF is read from your device, processed in memory and saved back to your device. You can switch off Wi-Fi after the page loads and it still works.
