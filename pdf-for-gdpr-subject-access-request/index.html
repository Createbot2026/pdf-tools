Prepare PDF disclosures for a subject access request

When responding to a SAR under UK GDPR, organisations must disclose the requester’s personal data but may need to withhold pages containing other people’s information. Pulling out the relevant pages locally keeps personal data off third-party servers.

Drop a file here or

    🔒 Runs entirely in your browser. Files are never uploaded.

    How to do it

    1. Identify pages that relate to the requester.
    2. Type those page numbers to create a disclosure file.
    3. For partial redaction within a page, use proper redaction software: drawing black boxes over text does not remove the text underneath.
    4. Merge the disclosure files and keep a record of what was withheld and why.

    Tips and limits

    • The ICO expects a response within one month in most cases.
    • Never "redact" by highlighting black in a PDF editor; the text is still selectable.
    • Keep an unredacted master copy securely.

    Frequently asked questions

    Does this tool redact text?

    No, it removes whole pages. In-page redaction needs a tool that deletes the underlying text. The Private PDF Toolkit extension is being built with this in mind.

    Is processing personal data here GDPR-safe?

    Files stay on your device; no data is transferred to us.

    Is my file uploaded anywhere?

    No. The tool runs in your browser with JavaScript. The PDF is read from your device, processed in memory and saved back to your device. You can switch off Wi-Fi after the page loads and it still works.
