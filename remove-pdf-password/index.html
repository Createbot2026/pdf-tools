Remove a PDF password (when you know it)

Unlock a PDF you already have the password for, so you can merge, compress or edit it. This is decryption with your password — not password cracking. We will not help bypass a password you do not know.

    1. Choose the protected PDF.
    2. Enter the current password.
    3. Press Remove password.
    4. Download the unlocked copy.

    Frequently asked questions

    Can you unlock a PDF without the password?

    No. That would be password cracking, which this site does not do.

    The tool says wrong password.

    The password does not match. Try the other password if the sender set both user and owner passwords.

    Is my file uploaded anywhere?

    No. The tool runs in your browser with JavaScript. The PDF is read from your device, processed in memory and saved back to your device. You can switch off Wi-Fi after the page loads and it still works.
