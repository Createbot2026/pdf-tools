Merge PDF files on Windows without Acrobat

Windows can print to PDF but cannot combine PDFs on its own, and Acrobat’s merge feature is paid. Edge or Chrome can run this tool locally instead.

Drop files here or

    🔒 Runs entirely in your browser. Files are never uploaded.

    How to do it

    1. Open this page in Edge or Chrome.
    2. Choose files (or drag them from File Explorer onto the box).
    3. Order with ↑ and press Merge.
    4. Find merged.pdf in your Downloads folder.

    Tips and limits

    • Drag-and-drop from File Explorer keeps your selection order.

    Frequently asked questions

    Do I need Adobe Acrobat?

    No. This works in any modern browser.

    Is my file uploaded anywhere?

    No. The tool runs in your browser with JavaScript. The PDF is read from your device, processed in memory and saved back to your device. You can switch off Wi-Fi after the page loads and it still works.
