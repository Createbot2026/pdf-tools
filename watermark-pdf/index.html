Add a text watermark to a PDF

Mark copies as draft, confidential or sample before you share them. The watermark is drawn on each page at the opacity you choose.

Drop a file here or

    🔒 Runs entirely in your browser. Files are never uploaded.

    How to do it

    1. Choose the PDF.
    2. Type the watermark text (e.g. DRAFT or CONFIDENTIAL).
    3. Adjust size, opacity and angle if you want.
    4. Press Add watermark and download.

    Tips and limits

    • Keep opacity around 0.2–0.3 so the document stays readable.
    • This is a visible stamp, not a secure DRM lock.

    Frequently asked questions

    Can I use an image logo?

    Not on this page yet — text only. The toolkit extension will add image watermarks.

    Is my file uploaded anywhere?

    No. The tool runs in your browser with JavaScript. The PDF is read from your device, processed in memory and saved back to your device. You can switch off Wi-Fi after the page loads and it still works.
