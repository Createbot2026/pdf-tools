Password-protect a PDF

Add an open-password so the file cannot be read without it. Encryption runs locally with qpdf (WebAssembly). Use a password you will remember — there is no recovery if you forget it.

Drop a file here or

    🔒 Runs entirely in your browser. Files are never uploaded.

    How to do it

    1. Choose the PDF.
    2. Enter and confirm a strong password.
    3. Press Protect PDF.
    4. Download the protected copy and store the password in a password manager.

    Tips and limits

    • Anyone with the password can open, print and copy unless you use a stricter permissions tool.
    • Email the file and the password by different channels.
    • Do not protect a file you might forget the password to without a backup of the unprotected original.

    Frequently asked questions

    What encryption is used?

    AES-256 (PDF revision suitable for modern readers).

    Can I remove the password later?

    Yes, with the Remove PDF password page, if you still know it.

    Is my file uploaded anywhere?

    No. The tool runs in your browser with JavaScript. The PDF is read from your device, processed in memory and saved back to your device. You can switch off Wi-Fi after the page loads and it still works.
